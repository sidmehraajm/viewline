Report a Bug

Found an issue while using Viewline? I appreciate your feedback.

Please report bugs by emailing the completed bug report template to me.

Before creating a bug report, please verify the following:

  • You are using the latest version of Viewline.
  • The issue can be reproduced consistently.
  • The problem is not already listed in the Known Issues section.

Download Bug Report Template

Download the template below, complete all relevant fields, and attach it to your email.

📥 Download Bug-Report.md

📥 Download Bug-Report.docx

Email Information

To: subing85@gmail.com

Subject:

[Viewline Bug] Short description of the issue

Attachments

When possible, include:

  • Screenshots
  • Screen recording
  • Log files
  • Sample media (if applicable)
  • Crash reports
  • Configuration files

Response Time

I will review your report and contact you if additional information is required.

Thank you for helping me improve Viewline.

Subin Gopi
